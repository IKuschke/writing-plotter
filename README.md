Автономное веб-приложение для подготовки рукописных конспектов, генерации G-Code (`.NC`), векторного экспорта в `.SVG` и прямого управления пишущим ЧПУ-плоттером **Jinqian** (прошивка GRBL 1.1f) через Web Serial API.

---

## 🚀 Основные возможности

* **🔄 Режим неразъемных тетрадей (Поворот на 180°):**
  * Возможность печати в сшитых тетрадях и блокнотах на кольцах/пружинах без помех со стороны каретки плоттера.
  * Режимы ориентации: `0° (Все прямо)`, `🔄 Нечетные 180° (Тетрадь)`, `🔄 Четные 180°` и `180° (Вверх ногами)`.
  * Автоматическое зеркалирование координат текста, полей и красной линии при перевороте.
  * Визуальный маркер на холсте (`⬆️ ВЕРХ ЛИСТА` / `⬇️ ВЕРХ ТЕТРАДИ ВНИЗУ`), подсказывающий оператору правильное положение тетради на столе.
* **💾 Автосохранение состояния (LocalStorage):**
  * Все внесенные изменения (текст конспекта, поля страницы, высота шрифта, скорости ЧПУ, высоты Z, цвет чернил, угол наклона и выбранная ориентация) автоматически сохраняются в памяти браузера.
  * При перезагрузке или повторном открытии страницы все настройки мгновенно восстанавливаются.
* **✍️ Встроенный Single-Stroke векторный шрифт:**
  * Высококачественные однолинейные траектории букв (полная кириллица, включая `ё`, `ъ`, `ы`, латиница, цифры и пунктуация `—`, `«`, `»`, `?`, `!`, `;`, `:`).
* **📁 Поддержка внешних SVG-шрифтов и листов Inkscape:**
  * Автоматическое распознавание символов, выравнивание по базовой линии (Baseline) и нормирование по высоте заглавных букв (Cap-Height).
* **🎲 Модуль «Живой почерк 2.0»:**
  * Интерактивное зерно генератора случайных чисел (`🎲 #Seed`).
  * Реалистичный микро-тремор пера на длинных участках траекторий.
  * Плавная гармоническая волна строк и динамический наклон символов.
* **📐 Интеллектуальная типографика:**
  * Слоговые переносы по правилам русского и английского языков.
  * **Smart Squeeze:** автоматическая подгонка длины строк под поля тетрадного листа (до 15%).
  * Привязка к сетке (клетка 5 мм, линейка 8 мм, сетка 10 мм).
* **⚡ Оптимизация траекторий (TSP):**
  * Алгоритм Nearest Neighbor с двухсторонним реверсом штрихов для сокращения времени холостого хода плоттера.
* **🔌 Прямая печать через USB:**
  * Управление плоттером прямо из браузера через **Web Serial API** на скорости 115200 бод.
* **📦 Экспорт данных:**
  * Скачивание управляющих программ в формате `.NC` (для LaserGRBL, UGS, Candle) и векторных `.SVG` по отдельности или всеми страницами сразу.

## ✍️ Доступные шрифты

В репозитории создана папка **[`fonts/`](./fonts/)**, в которой собирается коллекция векторных однострочных шрифтов.

**Как использовать шрифт из коллекции:**
1. Скачайте понравившийся `.svg` файл из папки [`fonts/`](./fonts/).
2. В редакторе нажмите кнопку **«📁 SVG Шрифт / лист»** и выберите скачанный файл.
3. Программа автоматически распознает глифы и применит шрифт к вашему тексту.

## ⚙️ Настройки оборудования и GRBL 1.1f

Программа оптимизирована под кинематику плоттеров **Jinqian** с шаговым двигателем на оси Z:

| Параметр | Значение | Описание |
| :--- | :--- | :--- |
| **Baud Rate** | `115200` | Скорость подключения по USB (CH340) |
| **$3** | `6` | Инверсия осей Y и Z |
| **$13** | `0` | Работа в миллиметрах |
| **$32** | `0` | Режим шпинделя (режим лазера выключен) |
| **Координаты (0,0)** | Нижний левый угол | Расчет по формуле: `Y_cnc = paperH - y_canvas` |
| **Перо ВВЕРХ (Воздух)** | `Z+3.0` | Скорость перемещения `F3000` |
| **Перо ВНИЗ (Бумага)** | `Z-3.0` | Скорость опускания `F1500` |

1. Скачайте файл `index.html`.
2. Откройте его в браузере **Google Chrome** или **Microsoft Edge**.

## 🛠️ Стек технологий
* **HTML5 / Canvas API** — рендеринг листа, разметки и предпросмотр траекторий.
* **Vanilla JavaScript** (ES6+) — векторный парсер SVG, генератор G-Code, алгоритмы TSP и LocalStorage.
* **Web Serial API** — прямой обмен данными с платой GRBL через USB.
* **CSS3** — интерфейс в стиле Ribbon Bar (MS Word).
