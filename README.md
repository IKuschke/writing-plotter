# 🖊️ Плоттер-Редактор PRO (Jinqian GRBL 1.1f)

Автономное веб-приложение для подготовки рукописных конспектов, генерации G-Code (.NC), векторного SVG и прямого управления 2-осевым пишущим ЧПУ-плоттером **Jinqian** (прошивка GRBL 1.1f) через Web Serial API.

## 🚀 Основные возможности

* **Полная автономность:** Работает как single-file веб-приложение в любом современном браузере (Chrome, Edge, Opera) без установки сторонних программ.
* **Встроенный Single-Stroke векторный шрифт:** Высококачественные однолинейные траектории букв (Кириллица, Латиница, цифры, знаки препинания `—`, `«`, `»`, `?`, `!`, `;` и др.).
* **Импорт рукописных шрифтов из SVG / Inkscape:** Автоматическое распознавание символов, выравнивание по базовой линии (Baseline) и нормирование по высоте заглавных букв (Cap-Height).
* **Модуль «Живой почерк 2.0»:**
  * Интерактивное зерно генератора случайных чисел (`🎲 #Seed`).
  * Реалистичный микро-тремор пера на длинных участках траекторий.
  * Плавная гармоническая волна строк и динамический наклон символов.
* **Интеллектуальная типографика:**
  * Слоговые переносы по правилам русского и английского языков.
  * **Smart Squeeze:** автоматическая подгонка длины строк под поля тетрадного листа.
  * Привязка к сетке (клетка 5 мм, линейка 8 мм, сетка 10 мм).
* **TSP-оптимизация траекторий:** Алгоритм Nearest Neighbor с двухсторонним реверсом штрихов для сокращения времени холостого хода.
* **Прямая печать через USB:** Управление плоттером прямо из браузера через **Web Serial API** на скорости 115200 бод.
* **Экспорт данных:** Скачивание управляющих программ в формате `.NC` (для LaserGRBL, UGS, Candle) и векторных `.SVG`.

## ⚙️ Настройки оборудования и GRBL 1.1f

Программа оптимизирована под кинематику плоттеров **Jinqian** с шаговым двигателем на оси Z:

| Параметр | Значение | Описание |
| :--- | :--- | :--- |
| **Baud Rate** | `115200` | Скорость подключения по USB (CH340) |
| **$3** | `6` | Инверсия осей Y и Z |
| **$13** | `0` | Работа в миллиметрах |
| **$32** | `0` | Режим шпинделя (режим лазера выключен) |
| **Координаты (0,0)** | Нижний левый угол | Расчет по формуле: `Y_cnc = paperH - y_canvas` |
| **Перо ВВЕРХ (Воздух)** | `Z+3.0` | Скорость перемещения `F3000` |
| **Перо ВНИЗ (Бумага)** | `Z-3.0` | Скорость опускания `F1500` |

## 📦 Быстрый старт

### Вариант 1. Запуск онлайн (GitHub Pages)
Просто перейдите по ссылке вашего репозитория:
`https://<ваш-логин>.github.io/<имя-репозитория>/`

### Вариант 2. Запуск локально
1. Скачайте файл `index.html` (или `plotter.html`).
2. Откройте его в браузере **Google Chrome** или **Microsoft Edge**.
3. Введите текст конспекта, настройте поля и шрифт.
4. Нажмите **«⚡ USB Плоттер»** для прямой отправки или **«💾 Скачать .NC»** для сохранения G-кода.

## 🛠️ Стек технологий
* **HTML5 / Canvas API** — рендеринг листа и предпросмотр траекторий.
* **Vanilla JavaScript** (ES6+) — векторный парсер, генератор G-Code, алгоритмы TSP.
* **Web Serial API** — прямой обмен данными с платой GRBL через USB.
* **CSS3** — адаптивный темный интерфейс в стиле Ribbon Bar (MS Word).
